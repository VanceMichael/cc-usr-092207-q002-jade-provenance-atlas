# 海外良渚玉器谱系库

整理海内外良渚玉器身份、流转记录与可修订学术判断。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括考古研究人员、海外博物馆、文献整理人员、公共查询用户。

资料所依据的领域事实如下：

- 欧美多家机构收藏良渚玉器且部分早期年代判断有误
- 研究院正在搭建海内外良渚玉器数据库
- 一些器物的更早出土与流转经历已经难以确定

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
