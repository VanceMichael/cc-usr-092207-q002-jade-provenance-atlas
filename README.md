# 海外良渚玉器谱系库

整理海内外良渚玉器身份、流转记录与可修订学术判断。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括考古研究人员、海外博物馆、文献整理人员、公共查询用户。

资料所依据的领域事实如下：

- 欧美多家机构收藏良渚玉器且部分早期年代判断有误
- 研究院正在搭建海内外良渚玉器数据库
- 一些器物的更早出土与流转经历已经难以确定

## 声明式谱系模型

谱系库不直接改写任何结论。尺寸、纹饰、修整痕迹、历次定名、收藏机构、旧藏人、交易或捐赠事件、出版物、图像权利与学术判断，统一记录为带来源、提出者、可信度、有效时间与可见性的**声明**（claim）：

- 新证据以 `supersede`（取代）或 `retract`（撤回）生成新声明，旧声明保留在历史中，旧目录的定名不会消失；
- 器物之间的“同一器物”判断是独立的**身份关联**（identity link），沿 candidate → accepted / rejected 单向流转，被否决的关联留痕，不做记录合并；
- 同一谓词允许多条 active 声明并存，学者可并列比较相互竞争的年代与流转假说；
- 可见性分 public / restricted / internal 三级，`public_view` 只投影获准公开的内容，馆方未公开材料不外泄；
- 任何结论都能回到原始记录（source）、提出者（proposer）与有效时间（valid_from / valid_to）。

`contracts/claims.schema.json` 规定声明与身份关联的结构，`src/claims.py` 提供校验、修订与公开视图，`fixtures/claims.json` 给出一件早年误判为周汉、后改定良渚的玉琮的完整示例（不含真实个人信息）。

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。

```sh
python -m unittest discover -s tests
```
